# 内容中心 Markdown 标准语法

内容中心基于 `@nuxt/content`，正文使用标准 Markdown。本文给出写作中最常用的语法速查。

## 标题

使用 `#` 引出标题，`##` / `###` 引出子标题。每个标题都会生成锚点，并自动出现在右侧目录中。

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 文本格式

| 风格 | 写法 | 渲染 |
| --- | --- | --- |
| 粗体 | `**粗体**` | **粗体** |
| 斜体 | `*斜体*` | *斜体* |
| 删除线 | `~~删除线~~` | ~~删除线~~ |

多种格式可以组合，例如 `` **_粗斜体_** `` 或 `~~**粗体删除线**~~`。

## 链接

用 `[文本](地址)` 创建链接；站内链接使用根相对路径。

```markdown
[快速开始](/content/document/documents/getting-started/quickstart)
```

## 列表

无序列表以 `-` 开头，有序列表以数字开头，子项缩进四个空格即可嵌套。

```markdown
- 无序项
- 另一项

1. 第一步
2. 第二步
```

## 代码

行内代码用反引号 `` `code` ``；代码块用三个反引号并标注语言，例如用 ` ```ts ` 围起 TypeScript 代码块。

## 引用

用 `>` 创建引用块，适合提示或强调。

> 先文档、再落码：任何代码改动都必须先有对应文档。

## 表格

用竖线分隔列，第二行用 `---` 分隔表头与表体。

| 字段 | 说明 |
| --- | --- |
| `title` | 标题 |
| `icon` | 图标（不可为空） |

## 写作约定

- 文件名用英文小写连字符（kebab-case）。
- 版本号用三段式、不带 `v` 前缀（如 `0.1.0`）。
- frontmatter 需携带 `title` / `createdAt` / `icon`，`icon` 按目录分配合适图标、不可为空。
