# ADR-0002：路由中英文命名规范

> **层级**：Tier 5 记录层 —— 正文不可修改（append-only）；变更须新开 ADR 并登记 `supersededBy`。

- **背景**：V2 路由中英文名称需统一规范，避免侧栏溢出、跨模块撞名、裸词歧义。
- **决策**：
  1. 英文标题 ≤17 字符（侧栏 16rem 不溢出）。
  2. 无裸词：通用词（Monitor / View / Type / Route / Policy / User / Log）须带模块限定（如 Spectrum Monitor、Device Type、Routing Policy）。
  3. 无跨模块重名（原 "Monitor"×2、"Policy"×2 已消除）。
  4. 按 NMS 行业标准命名：Transmission（传输）、Device Management（设备纳管）等。
  5. 中文与英文在 `i18n/locales/{cn,en}.json` 的 `pages.*` 对齐（55 项）。
- **影响**：`i18n/locales/cn.json`、`en.json` 的 `pages` 段；`useNavigation.ts` 以 `pages.<route.name>.title` 取标题。
