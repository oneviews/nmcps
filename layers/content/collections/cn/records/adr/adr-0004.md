# ADR-0004：文档体系权威金字塔落地

> **层级**：Tier 5 记录层 —— 正文不可修改（append-only）；变更须新开 ADR 并登记 `supersededBy`。

- **背景**：S0 建立了文档体系骨架（`NMCPS-GOV-001` 章程、`NMCPS-GOV-003` doc-map），但权威金字塔 Tier 1~3 几乎为空（仅 `NMCPS-ARCH-004` 内容中心架构）。「先文档、再落码」要求先补齐各层文档，再允许对应域落码。
- **决策**：

  | Tier | 层 | 新增 docId |
  | :---: | :--- | :--- |
  | 1 | 架构层 | ARCH-001 通信面 / ARCH-002 数据源 / ARCH-003 IAM |
  | 2 | 领域基准 | DESIGN-001~007（topology / spectrum / transmission / device / system / scenario / dashboard） |
  | 3 | 契约层 | CONTRACT-001 共享类型 / CONTRACT-002 指标契约 |

  共 12 篇，`authority: normative`、`status: draft`（待评审升 baseline）；`dependsOn` 只向上引用（Tier 0~1）；内容提炼自 v1（`_reference/nmcps-v1`）架构与 IAM 基准。
- **影响**：doc-map（`NMCPS-GOV-003`）登记 12 篇受治理文档（版本 0.4.0 → 0.6.0）；`shared/constants/docIds.ts` 登记 12 个映射；权威金字塔完整（Tier 0~5 共 18 篇）。
