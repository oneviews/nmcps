# ADR-0003：路由排序规范

> **层级**：Tier 5 记录层 —— 正文不可修改（append-only）；变更须新开 ADR 并登记 `supersededBy`。

- **背景**：V2 路由排序需对齐 1.0（`_reference/nmcps-v1`）的 `meta.sort` 顺序。
- **决策**：
  - 根模块顺序（sort 升序）：dashboard(1) → scenario(2) → device(3) → spectrum(4) → topology(5) → transmission(6) → system(7) → content(8)；user(9, hide) 进用户菜单。
  - 子路由顺序：scenario = task-planning(0)→sim-generation(1)→plan-generation(2)→dispatch(3)；device = type(1)→device(2)→mesh(3)→route(4)→policy(5)；spectrum = monitor(1)→resolution(2)→waterfall(3)→view(4)→pool(5)→rrm(6)→recommend(7)；system = user(1)→policy(2)→permission(3)→log(4)；content = document(1)→article(2)→release(3)→metadata(4)；user = profile(1)→preference(2)→notification(3)→security(4)→inbox(5)。
  - 根页跳转指向首个子页（min sort）。
- **影响**：各页面 `definePageMeta({ sort })`；根页 `navigateTo` 目标。
