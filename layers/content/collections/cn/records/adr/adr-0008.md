# ADR-0008：恢复站点下载落地页与首页入口

> **层级**：Tier 5 记录层 —— 正文不可修改（append-only）；变更须新开 ADR 并登记 `supersededBy`。

- **背景**：
  1. 2.0 的用户偏好重构（`cc998e9`）把 `app/pages/index.vue` 从「Logo + 平台检测 + 多格式下载 + GitHub Release 链接」的落地页，替换为 `onMounted(() => navigateTo('/dashboard/overview'))` 的重定向。落地页删除后，`app/layouts/home.vue`、i18n 的 `pages.index.*`（cn/en 均已存在）、`app.config.ts` 的 `downloads` 数据、`useOS` 组合式（已随重构删除）都变成无人消费的孤儿资源。
  2. 下载入口因此丢失：站点没有页面能告诉用户当前版本、各平台安装包与 Release 链接；而 404 页「回到首页」与 `SiteNavbar` 的 logo 都指向 `/`，`/` 只剩一条重定向。
  3. 安装包由 CI 上传 GitHub Release，`public/downloads/README.md` 已明确「二进制不进 `public/`」（否则会被打进 Tauri 二进制，体积膨胀数百 MB）。页面只需拼接下载 URL，不依赖本地静态文件。
- **决策**：
  1. **`/` 恢复为下载落地页**（`definePageMeta({ layout: "home" })`），不再自动跳转控制台；控制台经 `SiteNavbar` 的站点导航进入，404「回到首页」与 logo 回到落地页。浏览器与桌面（Tauri）同构，不做环境分叉。
  2. **恢复 `app/composables/useOS.ts`**：按 UA 判定 `windows / macos / linux / android / ios / unknown`。顺序有约束——iOS 早于 macOS（iPadOS 13+ 桌面模式会伪装成 Macintosh），Android 早于 Linux（Android UA 含 `Linux`）。`ios` / `unknown` 落到「暂无安装包，请选择其他平台」分支。
  3. **主按钮取该平台 `files[0]`**，即该平台主推格式；「其他格式（n）」下拉只列剩余 `n` 个格式。历史实现把 `files[0]` 也放进下拉，文案计数与列表条数相差 1（下拉 6 项、文案写 5），本次修正为一致。
  4. **下载 URL = `downloads.basePath`（去尾斜杠）+ `encodeURIComponent(文件名)`**，避免出现 `//` 或未编码字符导致 CDN 404。
  5. **版本与文件名只以 `app.config.ts` 的 `downloads` 为事实源**：页面不硬编码版本号，版本号升位只改 `app.config.ts` 与 bump 流程。
  6. **不新增依赖、不新增 i18n 键、不新增接口**：复用现有 `pages.index.*` 键（`download` / `detectedUsing` / `noPackage` / `downloadVersion` / `otherFormats` / `version` / `otherPlatforms` / `starOnGithub` / `madeBy`）。
- **影响**：
  - `app/pages/index.vue` 由重定向改为落地页（新增 `useOS`）；`app/layouts/home.vue`、`SiteNavbar`、`SvgoLogo` 重新被消费。
  - 桌面端首屏从「直达控制台」回到「落地页」，用户经站点导航进入控制台 —— 与 2.0 之前的行为一致。
  - `scripts/check-ui.mjs` 增加 4 项落地页断言（标题、平台检测文案、Release 链接前缀、链接数），总数由 21 项增至 25 项；控制台检查改为直接访问 `/dashboard/overview`，不再依赖 `/` 的重定向。
- **备选方案（未采用）**：
  - **保留 `/` 重定向，另建 `/download`**：站点内没有任何导航指向它，下载入口实际仍不可达，等于没恢复。
  - **仅桌面端（`isTauri()`）重定向到控制台**：同一路径出现两种首屏，`check:ui` 与文档都要分叉；且桌面用户点 logo 会被弹回控制台，下载页在桌面端永远不可见。
  - **把安装包放回 `public/downloads`**：`public/` 会被打进 Tauri 二进制，体积与升级成本不可接受（`public/downloads/README.md` 已否决）。
  - **在页面里写死版本号与文件名**：与 bump 流程脱钩，必然漂移。
- **遗留**：
  - 页面数据仍是构建期静态的 `app.config.ts`。动态发布（版本列表、更新通道、校验和、发布说明）应由 BFF 提供（见 `NMCPS-ADR-0007`），例如 `GET /api/ota/releases`；需先在 `GATEWAY_RESOURCES` 登记资源，并对 release 不存在的情况做校验，避免出现死链或 404。
  - CPU 架构（x64 / arm64）目前只能靠下拉手动选择：UA 无法可靠给出架构，改用 `navigator.userAgentData.getHighEntropyValues(['architecture'])` 是可行增强。
  - 校验和、签名与安装说明（macOS 首次运行需 `xattr -c /Applications/nmcps.app`）尚未上页面。
  - 会话 / 令牌模型顺延为 **ADR-0009**：`NMCPS-ADR-0007` 的遗留项原写作「需 ADR-0008」，因 0008 已被本决策占用而顺延。
