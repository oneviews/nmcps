# ADR-0022：Mininet 实验台全量功能并入与旧前端退役

> **层级**：Tier 5 记录层 —— 正文发布后只追加；后续修正用 `##` 追加节，不回改已发布结论。
> **与 ADR-0020 / ADR-0021 的关系**：ADR-0020 开了只读通道并把写操作、终端、抓包、WS 留作未决；ADR-0021 定了租户隔离、权限位、台账与审计原则，并用 P4 门禁挡住终端与抓包。本 ADR 回答这两个未决项，并把「旧 Vite 前端退役」写成可验收的终点。
> **状态**：需求方于 2026-11-16 明确目标——「彻底复刻 5173 到 `/scenario/simulator`，然后废弃 mininet 前端，只保留纯后端」。本 ADR 是该目标的技术裁决，实施按 §九 六段推进。

---

## 一、裁决（速览）

| 编号 | 裁决 | 说明 |
| :--- | :--- | :--- |
| **D1** | 写端点**按 `(method, 模板)` 逐条登记**，不按前缀放行 | 28 条写端点进入 `MININET_ROUTES`；未登记仍 `404 bff_resource_not_allowed`，动词不符仍 `405 bff_method_not_allowed`。白名单本身就是能力边界，不设运行时总开关。 |
| **D2** | 写能力按**权限位分档**，一条端点一个权限位 | `lab:create` / `lab:operate` / `lab:delete` / `lab:sniffer` 各自独立；`import_json`、`full_reset` 需**双权限**；跨档不隐含。 |
| **D3** | `channel` 能力位改为**按会话计算** | `GET /api/lab/channel` 返回 `writeEnabled` 与按动作分组的 `capabilities`；页面先读能力位再渲染按钮，不得「先渲染再等 405」。 |
| **D4** | 写操作**先审计、后执行**，高风险动作审计失败即拒绝 | 审计 outbox 落 `.data/audit/lab-audit.jsonl`（append-only，按天分片）；写盘失败回 `503 audit_unavailable`。 |
| **D5** | 同一网络**同时只允许一个在途写操作** | 台账租户级互斥 + 网络级锁；冲突回 `409 lab_operation_in_progress`，不做「先排队再覆盖」。 |
| **D6** | 四个 WebSocket 走**同源 `/lab-ws/*` + 短时票** | `POST /api/lab/ws-ticket` 签 HMAC 票（TTL 60 秒、一次性、绑定 `sub`/`tid`/`kind`/`target`）；浏览器不直连 `:8000`。 |
| **D7** | 导出走**独立内容类型通道**，不进 `ApiResponse` 信封 | `GET /api/lab/export/{json,script,pcap}`：前两者 `text/plain`，pcap 为二进制附件；pcap 需 `lab:sniffer`。 |
| **D8** | 旧 Vite 前端**复刻完成即退役** | `mininet_gui_frontend` 从部署与文档移除，`services/mininet-api` 只留纯后端；不再「双写」或「只读参考」。 |
| **D9** | 上游 CORS 关闭，浏览器只经 BFF | 后端不再需要 `Access-Control-Allow-Origin: *`；反代之外不暴露 8000。 |
| **D10** | 术语与所有权不变 | 上游节点 / 链路 / 流 ID **不是**权限凭据；租户只来自签名会话；生产拓扑与实验拓扑仍不混用。 |

## 二、写端点白名单与权限分档

以 `services/mininet-api` 的 FastAPI 路由为唯一事实源（`@app.<method>` 扫描结果），共 **28 条写端点**：

| 权限位 | 端点（上游路径） | 语义 |
| :--- | :--- | :--- |
| `lab:create` | `POST /api/mininet/start`、`POST /hosts`、`POST /switches`、`POST /routers`、`POST /nats`、`POST /controllers`、`POST /links` | 建网与加节点 / 加链路 |
| `lab:operate` | `POST /stop`、`POST /reset`、`POST /node_position`、`POST /associate_switch`、`POST /flows`、`POST /pingall`、`POST /iperf`、`PATCH /hosts/{host_id}`、`PATCH /routers/{router_id}`、`PUT /links`、`PUT /controllers/{controller_id}`、`PUT /switches/{switch_id}/openflow`、`DELETE /delete_link/{src_id}/{dst_id}`、`DELETE /remove_association/{src_id}/{dst_id}`、`DELETE /flows`、`DELETE /flows/{switch_id}/{flow_id}` | 改网络、跑测试、改流表 |
| `lab:delete` | `DELETE /delete_node/{node_id}` | 删节点（连带其链路） |
| `lab:delete` + `lab:create` | `POST /full_reset`、`POST /import_json` | 破坏性重建：先清空再建，缺任一权限一律 403 |
| `lab:sniffer` | `POST /sniffer/start`、`POST /sniffer/stop` | 抓包启停（`lab:read` 不足以读取抓包结果） |

**仍需 `lab:read` 的部分**：`GET /export_json`、`GET /export_script`；`GET /sniffer/export` 额外要求 `lab:sniffer`。

**不开放**：无。本 ADR 之后，上游 20 条 GET（17 条查询 + 3 条导出通道）与 28 条写端点全部可达（受权限位与台账约束），这是「彻底复刻」的定义。

## 三、失败语义（在 ADR-0020 / ADR-0021 之上追加）

| 情形 | 状态 / message |
| :--- | :--- |
| 会话有效但缺该端点所需权限位 | `403 lab_permission_denied` |
| 台账未命中 / 非本租户 | `404 lab_resource_not_found`（不得回 403） |
| 同一网络已有在途写操作 | `409 lab_operation_in_progress` |
| 同租户已有运行中网络（`start` / `import_json`） | `409 lab_network_already_running` |
| 审计写入失败 | `503 audit_unavailable`（高风险动作不得「先做后补」） |
| 票过期 / 重放 / 绑定不符 | `401 lab_ws_ticket_invalid` |
| 写端点已登记但上游 405 | `502 upstream_method_misconfigured`（配置错误，不是用户错误） |

**禁止**：把 `lab:read` 当作写权限的兜底；用前端禁用代替权限判定；把「网络内存在」与「有权操作」合并成同一状态码。

## 四、WebSocket 票与转发

```
浏览器 ──POST /api/lab/ws-ticket {kind,target}──▶ BFF（校验会话 + 权限位 + 台账）
       ◀── {ticket, expiresAt, url:"/lab-ws/terminal?ticket=…"} ──
浏览器 ──WS /lab-ws/terminal?ticket=…──▶ Nitro（crossws 升级）
                                            ├─校验 HMAC / TTL / 一次性 / 绑定
                                            ├─建连 ws://<租户实例>/api/mininet/terminal/{node}
                                            └─双向透传（不落内容，仅记时长）
```

| 项 | 值 |
| :--- | :--- |
| 票载体 | `HMAC-SHA256(secret, "v1|kind|target|sub|tid|exp|jti")`，Base64URL |
| TTL | 60 秒（`expiresAt` 由服务端给出，客户端不得续期） |
| 一次性 | `jti` 在 BFF 内存 + 台账中标记已用，重放回 401 |
| 绑定 | `kind` / `target` 必须与升级请求完全一致；`sub`/`tid` 取自会话，不接受查询参数 |
| 权限位 | `terminal` → `lab:terminal`；`sniffer` → `lab:sniffer`；`monitor` / `logs` → `lab:read` |
| 记录 | 只记会话开始 / 结束 / 目标 / 时长 / `request_id`；**不记录**终端输入与抓包载荷 |

**为什么不许浏览器直连 8000**：直连需要把上游地址下发浏览器，等于绕开台账与权限位；票只能证明「BFF 放行过」，不能证明「每次都放行」。

## 五、导出与导入

| 动作 | 通道 | 内容类型 | 权限 |
| :--- | :--- | :--- | :--- |
| 导出 JSON / 脚本 | `GET /api/lab/export/json`、`/export/script` | `text/plain; charset=utf-8` | `lab:read` |
| 导出抓包 | `GET /api/lab/export/pcap` | `application/vnd.tcpdump.pcap`，`Content-Disposition: attachment` | `lab:sniffer` |
| 导入 JSON | `POST /api/lab/import_json` | JSON 信封 | `lab:delete` + `lab:create` |

导出**不复用** `[...slug].ts` 的 JSON 信封：`ApiResponse` 会把文本包成 JSON 字符串，破坏 `wget` / 浏览器另存与 pcap 二进制流。文件名由 BFF 生成（`lab-<network_id>-<timestamp>.<ext>`），不信任上游 `Content-Disposition`。

## 七、旧前端退役步骤

1. 复刻验收：§六 每一行在 `/scenario/simulator` 有等价入口，且 `check:ui` 覆盖关键路径。
2. 冻结：`mininet_gui_frontend` 停止新增功能，仅在复刻期间作行为对照。
3. 退役：删除 `mininet_gui_frontend` 目录与部署单元；`services/mininet-api` 的 CORS 关闭，只经反代暴露。
4. 收口：`.clinerules/11-lab-ui` 与 `docs/ai/lab-boundary.md` 去掉「只读阶段」「只作参考」条款，改指向本 ADR；`NMCPS-ADR-0020` 的 D2/D5 由本 ADR 追加节标注「已由 ADR-0022 放开」。
5. 遗留：`mininet_gui_backend` 包名与 `cli.py` 保持不变（纯后端），不因前端退役而改名。

## 八、被否决的选项

| 选项 | 否决理由 |
| :--- | :--- |
| 保留旧前端并行运行 | 两套 UI 各自演进必然漂移；写操作对同一 `app.net` 竞争，前端无法自证一致。 |
| 浏览器直连 8000 + 后端自带 ticket 校验 | 需要向下发上游地址，绕开 BFF 台账；且后端无会话概念，无法绑定租户。 |
| 用一个总开关 `allowWrite` 放行全部写端点 | 粒度太粗：`full_reset` 与 `node_position` 风险等级不同，必须逐端点一个权限位。 |
| 只做前端禁用、后端继续 405 | 「彻底复刻」不可达；且前端禁用不是权限边界。 |
| 把导出继续塞进 `ApiResponse` | 文本 / pcap 会被二次编码，`Content-Disposition` 丢失。 |
| 直接整目录复制旧 Vue 代码 | 旧前端是 Options API + 全局事件 + 手写样式体系，与 `layers/scenario` 的 Nuxt UI v4 / i18n / 只读画布模型冲突；复制会引入第二套设计 token。 |

## 九、实施顺序与门禁

| 段 | 内容 | 完成条件 |
| :--- | :--- | :--- |
| **W1** | 写白名单 + 权限分档 + 审计 outbox + `channel` 能力位 + 串行锁 | `check:lab-bff` 扩到 60+ 项：28 条写端点逐条「有权放行 / 无权 403 / 未登记 404 / 上游零命中」，审计 503 路径可复现 |
| **W2** | 拓扑编辑：增删节点 / 连线 / 位置 / openflow / 流表 | 画布可增删并与 `GET` 台账一致；`check:ui` 覆盖一次新增与一次删除 |
| **W3** | 运行控制：`start` / `stop` / `reset` / `full_reset` / `pingall` / `iperf` | 409 单网络与 409 在途互斥均可复现 |
| **W4** | 导出 / 导入（含 pcap） | 三种内容类型直连可下载；`import_json` 双权限断言 |
| **W5** | 四个 WebSocket + 票 | 票过期 / 重放 / 绑定不符三条 401 有断言；终端与抓包只对显式授权角色可见 |
| **W6** | 旧前端退役 + 文档收口 | `mininet_gui_frontend` 删除；`.clinerules` 与 `lab-boundary.md` 已改；`pnpm check:doc-system` / `check:i18n` / `lint` / `typecheck` 全绿 |

**门禁**：W1 未绿不得开 W2（否则前端先有按钮、后端先有 403）；W5 未绿不得在 UI 渲染终端与抓包入口；W6 未完成不得宣称「已退役」。

> **实施状态（2026-11-16）**：W1 已落地 —— `MININET_ROUTES` 扩到 45 条（17 查询 + 28 写，逐条带权限位）；`/api/lab/**` 判定顺序改为会话 → 路径 → 权限位 → 台账 → 审计 → 加锁 → 出站；新增 `labAudit.ts`（`.data/audit/lab-audit-<date>.jsonl`，失败回 503）、`labLocks.ts`（同网络在途写 409）、`channel` 的 `capabilities` 按会话计算；`check:lab-bff` 69/69 全绿（新增 ⓪ 写端点分档、⑧ 写通道、⑨ 审计失败关闭三组），`check:lab-tenancy` 22/22（白名单权限位 ⊆ 矩阵、双权限、sniffer 独立）。多权限位判定收敛到纯函数 `hasLabPermissions()`，`[...slug].ts` 与 `authorizeLabAll()` 共用一份。

> **W5 Webshell 观感收口（2026-11-17）**：真 PTY 的输出**带 ANSI 颜色码与 `\r` 重绘**，原样贴进 `<pre>` 会把提示符显示成 `^[[1;32mroot@h1:/#`，进度条也会铺成一堆行（`10%\r50%`）。新增纯函数 `labTerminalTextOf()`（`layers/scenario/shared/types/labWs.ts`）：CSI 序列（`ESC[` … 终止字节）、OSC 标题（`ESC]` … `BEL` / `ESC\`）一律剥掉，行内 `\r` 取最后一段（真 PTY 用它覆盖同一行），退格删前一个字符，`\r\n` 仍是换行 —— 用逐字符扫描而不是正则，避免 `no-control-regex` 与跨行转义误伤。面板（`SimulatorNetworkTools`）因此多了三处：输出按清洗后的文本渲染并**自动滚到底**（追加流不跟随就看不到刚敲那条命令的回显）；「中断」发 `0x03`（PTY 的中断字节），不是发字面量 `^C`；「清屏」只清浏览器侧转写并清掉上一条错误行，**不断流**（PTY 没有标准清屏序列，远端屏幕要清得自己敲 `clear`）。`useLabWsChannel()` 相应导出 `clear()`。假上游的终端问候帧改成**带颜色码**（`MININET_TERMINAL_BANNER = ESC[1;32m…ESC[0m`）并对 `0x03` 回 `^C`（`MININET_TERMINAL_INTERRUPT_ECHO`），于是三条新断言都有真实取证：问候帧的 ESC 在 BFF 侧原样穿过、在面板里一个不剩；中断不是 `echo:^C`；清屏后仍是「已连接」。同一轮修掉一处**假数据**：`finiteNumber()` 原先用 `Number(value)` 兜底，`null` 会被算成 `0`、`true` 算成 `1`，监控里缺失的速率于是显示成 `0 Gbit/s`（把「读不到」说成「没有流量」）—— 现在只收真数字与非空字符串数字。断言：`check:lab-bff` ⑬ 新增 1 条（115 → 116：`0x03` 原样上行、上游回 `^C`、BFF 不吞控制字节），`check:ui` 11.8 新增 3 条（269 → 272：问候帧 ANSI 洗掉 / 中断按钮 / 清屏不断流）；新增 `pnpm check:lab-ws`（`scripts/check-lab-ws.ts`，21 项：四通道登记表与权限位、`target` 四种形状、上游地址拼接、票归一、监控帧 / 采样归一、PTY 清洗），与 `check:lab-flows` / `check:lab-run` / `check:lab-tenancy` 同族归 Lab 本地自检，不进 `ci.yml`。

## 十、遗留风险

1. **上游 `full_reset` 无二次确认参数**：BFF 只能靠 `lab:delete` + 显式 `confirm: "<network_id>"` 请求体窗口校验，防止误触；上游不支持幂等键。
2. **单实例全局 `app.net`**：本 ADR 不改变 ADR-0021 D1；W3 的 409 只在「同租户」成立，跨租户仍依赖每租户实例。
3. **审计留存**：`.data/audit/*.jsonl` 是过渡实现，长期需外部审计存储与保留期策略。
4. **WS 透传在 Nitro 的资源模型**：`crossws` 单连接占一个事件循环任务，需在部署面限制并发终端数（默认每租户 4）。
5. **旧前端删除不可回滚**：删除前须打 tag `legacy-mininet-gui-final`，保证行为对照可追溯。
