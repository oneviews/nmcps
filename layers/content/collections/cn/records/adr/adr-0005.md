# ADR-0005：en 双语镜像与双语接入

> **层级**：Tier 5 记录层 —— 正文不可修改（append-only）；变更须新开 ADR 并登记 `supersededBy`。

- **背景**：内容中心以 cn 为权威语言、en 为镜像（docId 一致、路径对齐），但 en 集合为空，且文档页硬编码 `content_cn` 集合，无法随 locale 切换。
- **决策**：
  1. 建立 en 镜像：18 篇英文文档 + 7 个 `.navigation.md`（英文目录标签），docId 与 cn 一一对应。
  2. 新增 `useContentCollection`：按 `useI18n().locale` 返回 `content_cn` / `content_en`。
  3. 文档列表页、详情页、侧栏搜索三处接入该 composable，`watch: [collection]` 触发 locale 切换时重新查询。
  4. 文档页文案（分组标签 / 空态 / 本页目录 / 未找到 / 返回列表）i18n 化。
- **影响**：`content_en` 集合解析（50 文件 = 25 cn + 25 en）；文档页与搜索双语展示；i18n `pages.content-document.*` 新增 8 个 key。
