# ADR-0001：模块改名

> **层级**：Tier 5 记录层 —— 正文不可修改（append-only）；变更须新开 ADR 并登记 `supersededBy`。

- **背景**：V2 路由中英文名称规范化，参照 1.0（`_reference/nmcps-v1`）。三个模块英文名不符合行业标准或语义不清（`protocol` 过于泛化、`monitor` 与 `spectrum-monitor` 英文撞名、`connector` 语义过窄）。
- **决策**：

  | 原模块 | 新模块 | 中文 | 英文 |
  | :--- | :--- | :--- | :--- |
  | protocol | transmission | 传输管控 | Transmission |
  | monitor | topology | 拓扑监控 | Topology |
  | connector | device | 设备组网 | Device |

  并同步：层文件夹（`layers/protocol→transmission` 等）、页面文件、`package.json` name/description、`nuxt.config.ts` `extends`、根页跳转、i18n `pages.*` key。
- **影响**：路由 path 变更（`/protocol/*→/transmission/*` 等）；i18n key 变更；子路由随父重命名（`monitor-topology→topology-monitor`、`connector-*→device-*` 等）。
