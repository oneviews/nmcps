# v2.0.0 内容中心发布

内容中心（Docs-as-Code 文档系统）发布首个完整版本。

## 本次交付

- **S0 治理基建**：文档体系章程、doc-map、frontmatter schema、`check:doc-system` 守卫。
- **S1 架构层**：通信面、数据源、IAM、内容中心共 4 篇 Tier 1 架构基准。
- **S2 领域基准**：拓扑 / 频谱 / 传输 / 设备 / 系统 / 场景 / 仪表盘共 7 篇 Tier 2 领域基准。
- **S3 契约层**：共享类型、指标共 2 篇 Tier 3 契约。
- **双语**：cn / en 双镜像（20 篇 × 2），文档页与搜索随 locale 切换。
- **三栏布局**：左树导航（高亮 + 中文/英文标签）、正文渲染、右目录滚动联动。

## 里程碑

| 版本 | 里程碑 |
| :--- | :--- |
| 0.1.0~0.3.0 | S0 治理基建 + 记录层 ADR |
| 0.4.0~0.6.0 | S1 架构层 + S2 领域基准 + S3 契约层 |
| 0.7.0~0.8.0 | en 双语镜像 + 权威金字塔推进 baseline |
