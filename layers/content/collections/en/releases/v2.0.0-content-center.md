# v2.0.0 Content Center Release

The content center (Docs-as-Code documentation system) ships its first complete release.

## Deliverables

- **S0 governance foundation**: charter, doc-map, frontmatter schema, `check:doc-system` guard.
- **S1 architecture**: transport, data source, IAM, content center — 4 Tier 1 baselines.
- **S2 domain baselines**: topology / spectrum / transmission / device / system / scenario / dashboard — 7 Tier 2 baselines.
- **S3 contracts**: shared types, metrics — 2 Tier 3 contracts.
- **Bilingual**: cn/en mirror (20 × 2), doc pages and search switch by locale.
- **Three-column layout**: left tree nav (highlight + labels), body rendering, right TOC scroll linkage.
