# ADR-0001: Module Renaming

> **Tier**: Tier 5 record layer — body is immutable (append-only); changes require a new ADR with `supersededBy`.

- **Background**: V2 route naming normalization, referencing 1.0 (`_reference/nmcps-v1`). Three module names were not industry-standard or were semantically unclear (`protocol` too generic, `monitor` collided with `spectrum-monitor`, `connector` too narrow).
- **Decision**:

  | Old module | New module | Chinese | English |
  | :--- | :--- | :--- | :--- |
  | protocol | transmission | 传输管控 | Transmission |
  | monitor | topology | 拓扑监控 | Topology |
  | connector | device | 设备组网 | Device |

  Also synced: layer folders (`layers/protocol→transmission`, etc.), page files, `package.json` name/description, `nuxt.config.ts` `extends`, root redirects, i18n `pages.*` keys.
- **Impact**: route path changes (`/protocol/*→/transmission/*`, etc.); i18n key changes; child routes renamed with parent (`monitor-topology→topology-monitor`, `connector-*→device-*`, etc.).
