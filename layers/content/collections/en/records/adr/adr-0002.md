# ADR-0002: Route Naming Conventions

> **Tier**: Tier 5 record layer — body is immutable (append-only); changes require a new ADR with `supersededBy`.

- **Background**: V2 route names need unified conventions to avoid sidebar overflow, cross-module collisions, and bare-word ambiguity.
- **Decision**:
  1. English titles ≤17 characters (no overflow in a 16rem sidebar).
  2. No bare words: generic words (Monitor / View / Type / Route / Policy / User / Log) must be module-qualified (e.g. Spectrum Monitor, Device Type, Routing Policy).
  3. No cross-module collisions (the duplicate "Monitor"×2 and "Policy"×2 were removed).
  4. NMS industry-standard naming: Transmission, Device Management, etc.
  5. Chinese and English aligned in `i18n/locales/{cn,en}.json` `pages.*` (55 entries).
- **Impact**: the `pages` section of `i18n/locales/cn.json` / `en.json`; `useNavigation.ts` reads titles via `pages.<route.name>.title`.
