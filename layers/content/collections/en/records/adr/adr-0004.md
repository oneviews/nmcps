# ADR-0004: Authority Pyramid Rollout

> **Tier**: Tier 5 record layer — body is immutable (append-only); changes require a new ADR with `supersededBy`.

- **Background**: S0 established the skeleton (`NMCPS-GOV-001` charter, `NMCPS-GOV-003` doc-map), but Tier 1~3 were nearly empty (only `NMCPS-ARCH-004`). "Docs before code" requires filling each layer before code lands in the corresponding domain.
- **Decision**:

  | Tier | Layer | Added docId |
  | :---: | :--- | :--- |
  | 1 | Architecture | ARCH-001 transport / ARCH-002 data source / ARCH-003 IAM |
  | 2 | Domain baselines | DESIGN-001~007 (topology / spectrum / transmission / device / system / scenario / dashboard) |
  | 3 | Contracts | CONTRACT-001 shared types / CONTRACT-002 metrics |

  12 docs total, `authority: normative`, `status: draft` (baseline after review); `dependsOn` references upward only (Tier 0~1); content distilled from v1 (`_reference/nmcps-v1`).
- **Impact**: doc-map (`NMCPS-GOV-003`) registered 12 governed docs (version 0.4.0 → 0.6.0); `shared/constants/docIds.ts` registered 12 mappings; the pyramid is complete (Tier 0~5, 18 docs).
