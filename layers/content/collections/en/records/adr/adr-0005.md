# ADR-0005: English Mirror & Bilingual Integration

> **Tier**: Tier 5 record layer — body is immutable (append-only); changes require a new ADR with `supersededBy`.

- **Background**: cn is authoritative, en is the mirror (same docId, aligned paths), but the en collection was empty and doc pages hardcoded the `content_cn` collection, so they could not switch by locale.
- **Decision**:
  1. Build the en mirror: 18 English docs + 7 `.navigation.md` (English labels), docId one-to-one with cn.
  2. Add `useContentCollection`: returns `content_cn` / `content_en` by `useI18n().locale`.
  3. Wire it into the doc list page, detail page, and sidebar search, with `watch: [collection]` re-querying on locale change.
  4. i18n-ize page copy (section labels / empty state / on-this-page / not-found / back-to-list).
- **Impact**: `content_en` parsed (50 files = 25 cn + 25 en); bilingual doc pages and search; 8 new `pages.content-document.*` i18n keys.
