# ADR-0003: Route Ordering Conventions

> **Tier**: Tier 5 record layer — body is immutable (append-only); changes require a new ADR with `supersededBy`.

- **Background**: V2 route ordering must align to the `meta.sort` order of 1.0 (`_reference/nmcps-v1`).
- **Decision**:
  - Root module order (sort ascending): dashboard(1) → scenario(2) → device(3) → spectrum(4) → topology(5) → transmission(6) → system(7) → content(8); user(9, hide) goes into the user menu.
  - Child route order: scenario = task-planning(0)→sim-generation(1)→plan-generation(2)→dispatch(3); device = type(1)→device(2)→mesh(3)→route(4)→policy(5); spectrum = monitor(1)→resolution(2)→waterfall(3)→view(4)→pool(5)→rrm(6)→recommend(7); system = user(1)→policy(2)→permission(3)→log(4); content = document(1)→article(2)→release(3)→metadata(4); user = profile(1)→preference(2)→notification(3)→security(4)→inbox(5).
  - Root redirect points to the first child page (min sort).
- **Impact**: per-page `definePageMeta({ sort })`; root `navigateTo` targets.
