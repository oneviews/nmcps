# Next Steps Recommendation

After completing any task, always proactively recommend the next action to the user using an A/B/C option format:

- Summarize the completed work and results first.
- Based on the current context, proactively list 2-5 specific follow-up options labeled A, B, C…
- Each option must be concrete and actionable; avoid vague wording.
- Place the most recommended option as A (the default suggestion).
- Do not wait for the user to ask — provide suggestions immediately when wrapping up a task.

## 收尾总结与响应语言

- **最后的总结必须使用中文（简体）书写**，内容包括：做了什么、验证结果（命令 + 关键输出）、注意事项/遗留项，以及 A/B/C 后续建议。
- 任务过程中的计划、进度说明、提问与风险提示，同样优先使用中文。
- 即使用户用其他语言提问，除非用户明确要求换语言，收尾总结仍用中文。
- 保持原样、不翻译的内容：代码、标识符、文件路径、命令、日志原文、commit message、`docId`。
- 文档正文语言遵循其所在 collection（`collections/cn` 用中文，`collections/en` 用英文），不受本规则影响；引用文档写 `docId（路径）`。
