# Lab UI

Mininet 实验台是 scenario 层里的一个受限功能区，不是第二个前端应用；页面与 BFF 路由同属 `layers/scenario`。

- 所有后端访问走 `useApi()` 或 `packages/mininet-client`，禁止在页面里写 axios 或硬编码 `http://...:8000`。
- 所有后端访问走 `useApi()` 或 `packages/mininet-client`，禁止在页面里写 axios 或硬编码 `http://...:8000`。
- 写能力位只读会话能力：页面先读 `GET /api/lab/channel` 的 `capabilities`，未授权动作不渲染，也不得先渲染再等 403/405；后端守卫永远是唯一权限边界（403 `lab_permission_denied` / 404 `lab_resource_not_found` / 409 冲突）。
- 拓扑编辑按能力位分档渲染：`create`（新增节点 / 连线）、`delete`（删节点）、`operate`（拖动落库 / OpenFlow / 删链路 / 流表写入）。没有 `operate` 时 `TopologyCanvas` 必须传 `:draggable="false"`，否则拖动会「看起来成功但没落库」。
- 新增节点的两个入口共用同一张表单：拓扑图**左侧**的纵向节点面板（`SimulatorNodePaletteRail`，五个类型图标可点可拖）里点一下用默认落点，拖到画布上则用放手位置。落点由画布反解成**图坐标**（`TopologyCanvas` 的 `canvasDrop`，已含缩放 / 平移）再换算成上游 `x` / `y`，页面不得自己算视口变换；`dropEnabled` 缺省关闭，只在有 `lab:create` 且正在拖拽时为 `true`。面板是画布**外面**的独立一列（W10）：画布容器是 flex 行，面板是第一个子项（`w-[72px] shrink-0 self-stretch`，与画布列同高、内容从顶部开始），不再 `absolute` 叠到画布上；类型按钮 48px / 图标 24px，别缩回 `size-10`。也别塞回工具栏 `UPopover`：那要「先点开菜单再拖」，菜单一收起拖源随之被拆掉，原生拖放永远到不了画布。

- `useApi().del(path, body)` 的请求体只服务「定位信息塞不进路径」的端点，目前仅 `DELETE /api/lab/flows`（`FlowRuleDelete` 用 `switch` + 可选 `match` 决定删哪些流）；其余 DELETE 一律无体，删哪个对象由路径段表达。给别的 DELETE 顺手加 body，等于让上游按「什么都不匹配」执行。
- 运行控制（`start` / `stop` / `pingall` / `iperf`）只按 `GET /api/lab/start` 的布尔运行态渲染：`true` 才给停止 / 探测 / 测速，`false` 才给启动，`null`（读不到）动作全禁用并显示「未知」。把「读不到」当成「没启动」，会让启动按钮对着已在跑的网络发请求，再拿上游 400 当失败。`POST /stop` 必须经确认弹窗 —— 上游会终止全部节点进程。
- 工具栏最左是复刻 1.0 版式的菜单栏（`NMCPS-ADR-0022` W2 修订 / W4 / W10）：做「文件」「视图」两组（`UDropdownMenu`，`xs` 按钮 + `carbon:chevron-down`），「工具 / 帮助」要 W5（抓包下载）的端点，不要先占一排点不动的位。「视图」四项（显示名称 / 显示主机 / 显示控制器 / 显示主机 IP）只过滤**渲染** —— `nodes` 仍是全量台账事实，默认落点与拖拽锚点换算都用全量，藏起来的主机不该把新节点放到空处。启动 / 停止 / 重启 / 重建不在这里：W10 起它们是设备栏顶部的常驻按钮（原「运行」菜单已删除，同一动作全页只有一个入口），右栏卡片只留运行态读数与连通性 / 吞吐结果。重启 = 停止 + 启动（上游没有 `restart` 端点），复用停网确认弹窗，且只在**运行中**可点（第一步就是 `POST /stop`，对已停的网调它只会拿到上游 400）。
- 「文件」装导入拓扑 / 导出 JSON / 导出脚本 / 导出拓扑 PNG / 导出地址规划（JSON）/ 设置…六项（`NMCPS-ADR-0022` W4 / W9）。导入项只负责唤隐藏 `<input type="file">`：读到文本先过 `parseLabImport()`（三类就地报错零请求 —— 空文件 / 非法 JSON / 形状不认；它同时接受 `nodes`+`edges` 的图形状和 `export_json` 的台账形状，controller ↔ switch 的关联线不算链路），再 `POST /api/lab/import_json`；`canImport` 要 `create` **和** `delete` 两个能力位（上游是有破坏性的重建通道），导入成功后重读台账而不是本地拼节点。导出只走 `GET /api/lab/export/{json|script|pcap}` + `useApi().download()`：导出是独立静态路由，返回的正文不是 `ApiResponse` 信封，文件名来自 BFF 的 `content-disposition`；把导出塞进 `[...slug]` 或 `api.get()` 会把 `.json` / `.py` / `.pcap` 变成被包了一层的字符串，也会丢掉文件名。`LAB_EXPORT_UPSTREAMS` 是导出种类白名单，且**权限位逐种类不同**：`json` / `script` 要 `lab:read`，`pcap` 要 `lab:sniffer`；未登记种类一律 `400 bff_path_invalid`（先判种类再判权限，路径写错不能伪装成 403）。
- W9 补的三项各有边界：PNG 由画布 SVG 序列化（`app/utils/graph/topologyPngExport.ts`），**必须先把每个元素的计算样式内联**再进 `<img>` —— 画布配色是 Tailwind class，脱离文档就没有 CSS，不内联会导出黑线 / 全透明图；`TopologyCanvas` 只为它多暴露一个 `svgElement`。地址规划读 `GET /api/lab/addressing_plan`（`lab:read`）下 JSON，不引 PDF 库（旧版是 jsPDF + autoTable）。「设置」只收旧弹窗里**仍无归属**的默认值（交换机类型 / 默认 OpenFlow / 默认链路属性，落 `localStorage`）：语言与主题在全局布局、显示开关在「视图」菜单，不复制第二份；链路属性只在填过时才随 `POST /links` 发 `options`（发了上游就按 `TCLink` 建链，需要 `tc` 权限）。
- 设备选取栏顶部（`SimulatorNodePaletteRail` 的 `#top` 插槽）常驻两组动作：运行控制（启动 / 停止 / 重启 / 重建，按能力位裁剪，见上一条）与「生成拓扑…」（复刻 1.0 `Side.vue` 首项 —— 那里建网动作也排在 palette 之上）。栏本身在 `create` 或 `operate` 任一为真时出现（只读会话不该多出一根空栏），没有 `create` 时类型列表为空。「生成拓扑」要 `lab:create`：`labGenerate.ts` 纯函数按 Single / Linear / Tree 出「节点清单 + 链路清单 + 坐标」，页面**串行**逐条 `POST /switches|/hosts|/links`（D5 同一网络只允许一个在途写，并发必 409），失败不回滚 —— 弹窗写「已建 N 个节点 / M 条链路 + 上游原话」后重读台账，单次上限 32 节点。一个动作只有一个入口：右栏不再重复一份。
- 栏本身是**透明**的（W11）：不铺底色、不描边、不投影、不挂整列 `title`（会和按钮提示叠成两个），看上去就是画布左侧的一条图标列而不是一张卡片。列内只留一条分割线（运行控制 ↔ 生成拓扑），别再加「栏顶 `border-b`」「重启 ↔ 重建」这类线。栏顶按钮**只有一种变体**（`neutral` + `ghost`，重建也不再用 `error` 色 —— 破坏性由提示与逐字确认弹窗承担），尺寸只允许「运行控制 36px / 生成拓扑 48px」这一处差异（后者与下面 48px 的类型图标对齐）。每个按钮都要有 `UTooltip`（不要用原生 `title`）；带原生 `disabled` 的按钮自己收不到指针事件，所以提示的触发器必须是外面那层 `<span class="inline-flex">`，否则停用态没有说明。
- 拖拽新增的**拖影只带图标**：`onPaletteDragStart()` 里用 `dataTransfer.setDragImage(按钮内那枚图标, 12, 12)`。默认拖影是整枚按钮快照，悬停底色与圆角方块会一起被复制，拖动过程中就是一个灰方块。
- 画布**常驻**，不许写成 `v-if="visibleNodes.length"`（W11 缺陷修复）：`drop` 只挂在 `TopologyCanvas` 的 `svg` 上，没节点时把画布换成占位文案，等于把「从零建网」的第一步（拖一个类型进空画布）变成死路。空态改成叠在画布上的 `pointer-events-none` 提示层，`check:ui` 11.6a 用 `full_reset` 之后那段 0 节点窗口守着这条回归。
- 画布右键菜单（`NMCPS-ADR-0022` W12）只对**节点**生效，空白处一律 `preventDefault` + 上报 `null`：菜单由 Nuxt UI 的 `UContextMenu` 包住画布容器渲染，`TopologyCanvas` 的 `contextMenu` 开关缺省 `false`（生产拓扑页保持浏览器原生菜单）。节点 `<g>` 的 `@contextmenu.stop` **不能** `preventDefault()` —— Reka 的 `ContextMenuTrigger` 在 `await nextTick()` 后才看 `event.defaultPrevented`，一挡掉菜单也就不弹了；空白处反过来必须挡掉。菜单项只复刻 1.0 的两项（打开 Webshell / 查看节点详情）：Webshell 要 `lab:terminal`，详情常驻（纯读）。「打开 Webshell」= 右栏切到 Webshell + `SimulatorNetworkTools` 暴露的 `openTerminalFor(id)`（`defineExpose`），不另写一套终端。别在菜单里加「删除节点」：删除入口在右栏，一个动作只有一个入口。
- 双击节点 / 链路打开详情弹窗（`NMCPS-ADR-0022` W13）走 `TopologyCanvas` 的 `activateOnDoubleClick`（缺省 `false`，保留生产页的双击收起下级）。弹窗里的「事实」是台账原样字段（页面手里那份），只有主机 / 路由器的默认路由与 ARP、链路的 tx/rx 才额外读 `GET /api/lab/stats/{id}` / `GET /api/lab/links/stats/{src}/{dst}`，读不到只降级那一块。编辑按能力位：主机 `PATCH /hosts/{id}`、路由器 `PATCH /routers/{id}`、链路 `PUT /links`，全部要 `lab:operate`；交换机不重复 OpenFlow / 流表入口（仍在右栏），控制器 / NAT 只读。校验与请求体只写在 `layers/scenario/shared/types/labDetails.ts` 的纯函数里，组件不自己拼一份；链路属性全空时**不发请求**（上游对空 `options` 只清台账、不回收 tc）。没有保存按钮时不许只留白：交换机（入口在右栏）、控制器 / NAT（上游只改台账、不重启控制器，NAT 连更新端点都没有）、缺 `lab:operate` 的会话各有一句就地只读原因（`lab-node-detail-readonly` / `lab-link-detail-readonly`），`check:ui` 11.14 守着这条；控制器 / NAT 只读是 ADR-0022 W13 的裁决，不再挂 W14。
- 「工具」菜单（`NMCPS-ADR-0022` W5）只在 `lab:sniffer` 时渲染，三项 = 开始抓包 / 停止抓包 / 下载 pcap；读数（`GET /api/lab/sniffer/state`，三态，读不到不回落成「未抓包」）放在右栏运行卡片里，动作入口只在菜单。开始抓包还要求网络在跑（上游对未启动回 400）。pcap 下载走 `GET /api/lab/export/pcap`，BFF 以 `fetchMininetBinary()` 取 `arrayBuffer` —— 走 `text()` 会把 `0xd4 0xc3` 解成 U+FFFD，文件打不开。
- 右栏是一块可折叠面板 + 一排五个标签页（Webshell / 日志 / 监控 / 网络 / 连通）：标签定义只有页面里的一份（`sideTabItems`，按能力位裁剪），内容由页面与 `SimulatorNetworkTools` 分担。观测三块（`SimulatorNetworkTools` + `useLabWsChannel(kind)`）：Webshell 要 `lab:terminal`，日志 / 监控只要 `lab:read`；两个能力位都没有时这三页都不渲染，且不会把用户留在空标签里。缺省停在「网络」—— 那是纯读的台账事实页，不依赖写能力位；「连通」要有 `lab:operate`（探测 / 测速）或 `lab:sniffer`（抓包读数）才出现。这三种可见性由 `check:ui` 11.9 固定为回归用例，且与真环境实测同形：实验台操作员（只 `lab:read`）右栏只剩 日志 / 监控 / 网络，**没有** Webshell、**没有**连通；租户管理员（含 `lab:operate`）有连通且探测 / 测速可用，仍**没有** Webshell、没有抓包读数 —— `lab:terminal` / `lab:sniffer` 不由 `lab:operate` 推导，别为了「让管理员也能看终端」给它加豁免。观测组件用 `v-show` 常驻：切到「网络 / 连通」只换视图，Webshell 的会话不被卸载。日志随标签打开自动建流、离开即断；监控只有一个目标（选节点 + 接口，接口清单只来自 `GET /api/lab/interfaces`），切走即停；Webshell 是**显式多会话**（每个节点一条标签，`useLabTerminalSessions()` 为每条会话维护一条 socket），切标签不算断开，只有标签上的 × 与收起右栏才断流 —— 别把「切到网络」实现成「把终端 socket 拆掉」。监控帧先过 `labMonitorFrameOf()`：上游 `Error: …` 文本要显示成错误行，不能当「暂无数据」吞掉。终端按键要翻成 PTY 字节（回车 `\r`、退格 `0x7f`、方向键 CSI、带修饰方向键 `CSI 1;<mod><letter>`、`Ctrl+字母` 发 `0x01–0x1A`、`Ctrl+Space` 发 `0x00`、`Alt+字母` 发 `ESC+字母`、F1–F12），带 `Ctrl` / `Alt` / `Meta` 的可打印键一律不上行，`Ctrl+V` 只走粘贴（绝不把 `v` 当输入）、IME 组字期间的 `keydown` 放行，回显交给 PTY，不做本地回显（否则一次输入两份）。终端输出先过 `labTerminalTextOf()`（剥 ANSI / OSC、按 `\r` 覆盖取最后一段、退格删字符）：真 PTY 一定带颜色码，原样渲染会把提示符显示成 `^[[1;32m`；「中断」发 `0x03` 而不是字面量 `^C`，「清屏」只清浏览器侧转写且不断流（远端屏幕要清得自己敲 `clear`）。渲染边界由 `NMCPS-ADR-0025`（`layers/content/collections/cn/records/adr/adr-0025.md`）裁决：全屏 TUI（`vi` / `top`）、颜色、宽字符对齐、窗口缩放**不支持**，这是裁决内的事实而不是待修缺陷 —— 别为此自研 CSI 光标定位（那等于重写终端模拟器），要真模拟器就按 ADR-0025 D5 新开 ADR 评估依赖。抓包**不**在观测三页里重复一份（启停在「工具」菜单、实时包在「连通」标签），一个动作仍然只有一个入口。
- 设备栏顶部的最后一项是破坏性重建（`POST /api/lab/full_reset`）：要 `create` + `delete` 双能力位，且弹窗要**逐字输入网络 ID**；BFF 侧同一值（`{ confirm: "<network_id>" }`）是硬闸门，缺失或不符回 `400 lab_confirm_required` 且不触达上游。成功后台账 `resources` 整体清空（`reset: true`），页面重读台账而不是本地清数组。
- `pnpm check:ui` 不自建 `.output`：脚本先比产物与源码的 mtime，产物比 `app` / `layers` / `shared` / `i18n` / `nuxt.config.ts` 旧就直接退出并提示 `pnpm build:server`。看到这条提示别再顺着失败用例排查，那测的是旧 bundle。
- 真机手验是 `pnpm check:lab-real`（`CHECK_REAL_MININET=1` 才开门，需 root 后端 `:8000` 与 `build:server`）：它自己建 `h1` / `h2` 与一条带 `bw` 的链路、起停网络并在结束时删掉，所以真后端非空实例时必须先 `full_reset`，别拿别人正在跑的拓扑做回归；`check:ui` / `check:lab-bff` 的假上游只会回显，证明不了真 bash 认不认那些按键字节。跳过（无该变量）不算通过。W10 起它还覆盖栏顶四个运行控制（11.10 四条）：点「停止 / 启动 / 重启」后读真后端 `is_started` 与 `GET /api/mininet/interfaces` 里 `h1` 的 `pid` —— 停止后 pid 读不到（Mininet 节点要 `start()` 才有 `pid`）、启动后拿到新进程、重启必须**换一个 pid**（只停不起 → 无 pid，只起不重建 → pid 不变），确认弹窗的「终止全部节点进程」/「先停止再启动」也要在正文里。W13 起还覆盖双击链路改带宽：真上游 `GET /links` / `GET /links/stats/{src}/{dst}` 回读新 `options.bw`、`intfs` 是真接口名、再双击输入框已是新值；`tc` 那一层只有脚本以 root 跑才断言（接口在主机自己的 netns 里，要 `nsenter -t <h1 pid> -n tc class show dev h1-eth0` 看 htb 类的 `rate`，不是 `tbf`），非 root 打 `⏭` 明示跳过（跳过不算已验）。
- WebSocket 统一走同源 `/lab-ws/*`：先用 `POST /api/lab/ws-ticket { kind, target? }` 换 60 秒一次性票，再由 BFF 验票（签名 / TTL / 一次性 / `kind`+`target` 绑定）后建连上游转发；组件不直接 `new WebSocket`，也不得向下发上游地址（`NMCPS-ADR-0022` D6）。抓包实时流已落地：`useLabSnifferStream()`（`layers/scenario/app/composables/useLabSnifferStream.ts`）负责换票 / 建连 / 断流，页面只在 `snifferActive === true` 时连，`null`（读不到）与 `false` 都不连；列表先由 `GET /api/lab/sniffer/history` 回填，上限 200 条。票只能由已登记种类签发（`LAB_WS_UPSTREAMS`，当前四条：`sniffer` / `terminal` / `logs` / `monitor`），未登记种类回 `400 lab_ws_kind_invalid`。
- 依赖 Mininet 的页面/画布使用 `client-only`，不在 SSR 阶段访问本地实验服务。
- 组件优先用 Nuxt UI v4 原生组件；沿用现有设计 token，不复制旧 Vite 的样式体系。
- 所有可见文案进 `i18n/locales/{cn,en}.json`，两边 key 与占位符一致。
- 新页面必须声明权限 meta；终端、抓包、reset 默认不显示，除非后端返回对应能力位。
- 租户与权限只信 BFF 会话；页面不得读取或提交 `x-tenant-id`，也不得把 `sim_id` / 节点 ID 当作权限判断依据（NMCPS-ADR-0021）。
- 终端、抓包默认不渲染；`lab:terminal` / `lab:sniffer` 必须单独授权，不能由 `lab:read` / `lab:operate` 推导。
- 仿真网页面是 `/scenario/simulator`（`layers/scenario/app/pages/scenario/simulator.vue`），复用生产 `TopologyCanvas` 展示台账拓扑，不另写一套画布。
